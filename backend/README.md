# Mon vieux Grimoire (Il doit être lancé sur backend et sur frontend)
Il faut avant toute chose vérifier qu'on dispose du fichier Environnement `.env` qui contient les paramètres
de l'application Grimoire. Ce fichier est à mettre dans l'arborescence du projet, juste à l'exterieur du 
repertoire (ou dossier) backend.

## Comment lancer le server sur le backend ? ### Avec npm ?
Se mettre sur le backend et faire la commande bash `npm install` pour installer les dépendances puis `npm start`
Faites la commande `npm start` qui lance `node server` ou `npm run dev` qui lance `nodemon server`.
Le server Node Express/mongoDB se lance sur `backend` sur le <port=4000>. 

## Comment lancer le projet sur le frontend ? ### Avec npm ?
Se mettre sur le repertoire du projet et taper : npm install (à faire une fois).
## npm run start : pour lancer le frontend <http://localhost:3000> ## 
Cela installera toutes les dépendances requises par l'application front-end, 
et lancera le server de développement qui affichera l'écran d'accueil.
